[스킬 마무리]
1) 오의 C - 검술의 정점
- 직선 막대 이펙트 대신 끝이 날카로운 비대칭 초승달형 참격 사용
- 좌우대칭이 아니라 한쪽으로 휘어진 곡률을 랜덤 적용
- 참격 중심점/각도/크기/곡률을 매 타격마다 분산
- 캐릭터 주변을 마구 난도질하는 느낌으로 7~10개의 참격 + 대형 마무리 참격 추가

2) 극의 A - 검술의 극
- 모든 타격 확정 치명타
- 치명타 배율 2배
- 적중 시 crit 효과음 재생
- 기존 돌/광석 뒤 LOS 무시 유지

3) 스킬 툴팁
- I / II / III 영역과 0/5 투자량 사이 간격 확대
- 투자량과 설명 시작 위치도 추가로 분리
- 설명 자동 줄바꿈 유지

- 검술 레벨 30

일지 제목:
[오의]새로운 경지를 깨우칠 것 같다.

목표:
- 어둠의 해골 30마리 사냥
- 게임 내부에서 어둠의 해골이 Bat 변종으로 처리되는 점까지 구분해서 카운트

완료 보상:
- 오의 비책 1개
- 오의 비책을 손에 들고 행동 버튼으로 사용하면 오의가 영구 해방됨

일지 제목:

목표:

퀘스트 완료:

- 깨달음의 물방울 1개 지급
