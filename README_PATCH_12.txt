SwordMastery PATCH 12 - COMBAT FEEL / COOLDOWN HUD
===================================================

덮어쓸 파일:
- ModEntry.cs
- ModConfig.cs
- Services/CombatService.cs

[데미지 기준]
장착한 검의 (최소 공격력 + 최대 공격력) / 2 를 기준 공격력으로 사용.

단발기:
- 시작값 = 검 평균 공격력의 130%
- SP 1포인트당 +2%p
- 스킬/단계에 따라 추가 보너스 존재

다단기:
- 시작값 = 검 평균 공격력의 75% "매 타격"
- SP 1포인트당 +1.5%p "매 타격"
- 상위 단계는 추가 보너스 존재

[쿨다운]
- 검사의 발걸음 A = 7초
- 참격 B = 3초
- 칼리코류 C = 5초
- 일섬 = 12초
- 검술의 정점 = 9.5초
- 보법의 극 = 쿨다운 없음

[이동 최대사거리]
검사의 발걸음:
- 1단계 2칸
- 2단계 3칸
- 3단계 4칸

일섬:
- 1단계 4칸
- 2단계 6칸
- 3단계 8칸

보법의 극:
- 1단계 2칸
- 2단계 4칸
- 3단계 6칸

벽/장애물에 부딪히면 최대사거리 전에 정지.

[일섬 폭]
- 1단계 = 1칸
- 2단계 = 5칸
- 3단계 = 10칸
단계가 오를수록 경로 전체에 다수의 참격 Arc가 발생하도록 강화.

[이펙트]
- 직선 막대기/레이저 형태 대신 곡선 참격 Arc 사용
- B 3단계 검기도 초승달 참격형
- 칼리코류 3/4/6타 각각 개별 참격 이펙트
- 스킬 사용 시 플레이어 검 휘두르기 애니메이션
- 검술의 극은 플레이어에게서 이펙트가 나오지 않고 감지된 몬스터에게 직접 참격 발생

[검술의 극 범위]
- 1단계 약 3.2칸
- 2단계 5칸
- 3단계 7.5칸

[쿨다운 HUD]
기초검술 A/B/C 및 선택한 액티브 오의의 아이콘을 실시간 표시.
남은 시간이 아이콘 어두운 마스크 + 초 단위 숫자로 표시됨.

GMCM:
- 쿨다운 HUD 표시 ON/OFF
- 쿨다운 HUD X 위치
- 쿨다운 HUD Y 위치

PATCH 09의 DEBUG GMCM 기능도 유지됨.
