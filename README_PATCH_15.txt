주요 수정
---------

1) 검기 이펙트
- 일정 굵기의 휘어진 막대기가 아니라 양 끝이 얇아지는 초승달형 참격으로 변경.
- 진행 방향을 향하도록 방향 수정.
- 기초검술 B 3단계와 오의 '검기' 모두 같은 초승달 계열 이펙트 사용.

2) 무기를 들지 않아도 액티브 기술 사용 가능
- 마지막으로 들었던 근접무기의 평균 공격력을 SaveData에 기억.
- 빈손/곡괭이/도끼 등으로 바꾼 뒤에도 마지막 무기 공격력을 기준으로 기술 데미지 계산.
- 오의 B '검기'는 정상 검 공격에 붙는 패시브이므로 실제 검 공격 시에만 발생.

3) 극의 A '검술의 극'
- 현재 들고 있는 도구 공격력과 완전히 분리.
- Infinity Blade 80~100의 평균값인 90을 독립 기준 공격력으로 사용.
- 1단계 약 3.2칸 / 2단계 5칸 / 3단계 7.5칸 반경.
- 플레이어가 아니라 감지된 몬스터 몸에서 참격 이펙트 발생.
- 바위/장애물이 사이에 있어도 범위 안 몬스터는 직접 타격.

4) 기초검술 B 3단계 검기
- 최대 사거리 6칸.
- 맵 벽/바위/나무 등 고형 장애물에 닿으면 소멸.
- 거리별 데미지 감소 유지.

5) 오의 B '검기'
- 바위/오브젝트는 통과하고 설정된 최대사거리까지 진행.
- 맵 자체의 벽은 통과하지 않음.
- 거리별 데미지 감소 유지.
- 몬스터 관통:
  1단계: 1회 적중 후 소멸 / 6칸
  2단계: 2회 관통 / 10칸
  3단계: 다수 관통 / 16칸
- 이펙트 크기:
  1단계 기존 크기
  2단계 기존 3단계급
  3단계는 같은 증가폭만큼 한 단계 더 확대.

6) 기초검술 C
- 축을 중심으로 도는 느낌 대신 정면 한 영역을 교차해서 연속으로 베는 이펙트.
- 매 타격마다 별도 참격이 겹쳐짐.
- 다단히트 간격을 5틱으로 단축.
- 바위 뒤의 적도 범위 안이면 타격.

7) 오의 C '검술의 정점'
- 주변을 난도질하는 고밀도 검격 이펙트.
- 한 타마다 굵고 큰 참격 2~3개가 서로 다른 각도로 겹침.
- 기초검술 C보다 처음부터 크고 굵음.
- 범위: 1단계 반경 2칸 / 2단계 3.5칸 / 3단계 5칸.
- 3 / 6 / 10회 타격.
- 다단히트 간격 4틱.
- 바위 뒤 적도 범위 안이면 타격.

8) DEBUG
GMCM > DEBUG 테스트 도구:
- [실행] 모든 스킬 활성화
  모든 기술을 15/15 MASTER, 오의/극의 해방.
  정상 분기 독점 규칙은 유지하며 선택 상태를 초기화해 원하는 분기를 다시 고를 수 있음.
- [받기] 해방 아이템 2종 지급
  오의 비책 + 깨달음의 물방울 지급.

9) 해방 아이템
- 오의 비책:
  파란 비법서 아이콘.
  손에 들고 행동 버튼을 누르면 오의 영구 해방.
- 깨달음의 물방울:
  푸른 물방울 아이콘.
  손에 들고 행동 버튼을 누르면 극의 영구 해방.
- 이미 해방된 상태에서는 소비하지 않음.

10) 장애물 뒤 타격
- 기초검술 B 1~2단계
- 기초검술 C
- 검술의 정점
- 검술의 극
위 기술은 범위 판정 시 지형 사이의 바위 때문에 공격이 막히지 않음.

11) 이동기 충돌
- 몬스터는 통과.
- 풀/잡초/섬유처럼 검으로 제거 가능한 장애물은 이동을 막지 않음.
- 바위/나무/맵 벽 등 단단한 장애물에서는 정지.
- 이동 후 경로 전체에 기술 데미지 적용.

12) 다단기 타격 간격
- 검사의 발걸음 3단계: 6틱
- 기초검술 C: 5틱
- 검술의 정점: 4틱

13) 데미지 규칙 유지
- 단발기: 검 평균 공격력 130% + SP당 4%p.
- 다단기: 매 타격 75% + SP당 2.5%p.
- 일섬: 99,999 고정 / 데미지 성장 없음.

14) 일섬 추가
- 실제 'crit' 치명타 효과음을 명시적으로 재생.
- 지나간 시작점~종점 전체에 직선 참격 잔상 추가.
- 기존의 화려한 경로 참격 이펙트도 함께 유지.
- 1/2/3단계 사거리 4/6/8칸.
- 폭 1/5/10칸.
- 12초 쿨다운.
