[기초검술 C 이펙트]
- 일정한 폭의 막대형 참격 제거
- 양끝이 날카롭고 중앙이 두꺼운 검날형 참격으로 변경
- 모든 검격이 같은 전방 초점을 통과하는 구조 유지
- 흰색 칼날 코어 + 청색 외곽광으로 표시

[오의 C - 검술의 정점]
- 막대형 이펙트 제거
- 굵고 긴 검날형 참격을 여러 각도로 중첩
- 외곽 광원 + 흰색 중심광 + 대형 교차 마무리 검격
- 기초검술 C보다 확실히 크고 화려하게 표시

[오의 A - 일섬]
사거리:
- 1단계: 5칸
- 2단계: 8칸 (기존 3단계 수준)
- 3단계: 현재 맵의 끝에 가까운 거리까지 돌진
  * 맵 벽/보호 대상 오브젝트 앞에서는 정지

공격 폭:
- 1단계: 1칸
- 2단계: 4칸
- 3단계: 9칸

유지:
- 99,999 확정 치명타
- crit 효과음
- 직선 빔형 이펙트

[광산 장애물 파괴]
일섬:
- 진행 경로 및 공격 폭 안의 돌/광석/잡초/섬유/나뭇가지/광산 상자·통류를 제거
- 상자(보관함), 제작기, 장식품, 농작물, 바닥, 일반 나무/과수, 가구 등은 보호

- 기존 몬스터 관통/거리별 피해감소 조건 유지
