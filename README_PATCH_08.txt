SwordMastery PATCH 08 - BASIC SKILLS

GitHub에 업로드/덮어쓰기:
- ModEntry.cs
- ModConfig.cs
- Services/CombatService.cs  (새 파일)

이번 패치에서 실제 구현되는 기초검술:

A. 검사의 발걸음
- 1단계: 전방 대쉬
- 2단계: 대쉬 경로 1회 베기
- 3단계: 대쉬 경로 4회 다단 베기
- 기본키 F6
- 쿨다운 약 0.6초

B. 참격
- 1단계: 전방 베기
- 2단계: 더 넓은 전방 베기
- 3단계: 직선으로 날아가는 검기
- 기본키 F7
- 쿨다운 약 0.5초

C. 칼리코류 검술
- 1단계: 전방 3회 타격
- 2단계: 넓은 전방 범위 4회 타격
- 3단계: 더 넓은 범위 6회 타격
- 기본키 F8
- 쿨다운 약 0.9초

공통:
- SP를 1 이상 투자해야 기술 사용 가능
- 스킬 총 투자 포인트가 늘수록 피해량 증가
- 현재는 MeleeWeapon을 들고 있어야 발동
- GMCM에서 A/B/C 단축키 변경 가능
- 전투 로직은 키 입력과 분리돼 있어서 Android 터치 버튼 연결 시 재사용 가능

주의:
- 이번 패치는 UI 파일을 포함하지 않음.
- 따라서 직전에 적용한 최신 UI(Layout Fix 02)는 그대로 유지됨.
