SwordMastery PATCH 30 - LANGUAGE SELECTOR / ENGLISH DEFAULT
=============================================================

Cumulative from PATCH 29.

Changed language behavior:
- Sword Mastery no longer follows the Stardew Valley game language.
- Default mod language is always English.
- Added a Mod Language option to GMCM.
- Selectable values:
  * English
  * 한국어
- Changing the language switches skill names, descriptions, HUD,
  GMCM labels, combat messages, quest text, and custom item text.
- Data/Objects and Data/Quests caches are invalidated when language
  is changed so localized game-data strings can refresh.

Default:
Language = English

This is the intended public Nexus behavior.
