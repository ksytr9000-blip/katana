검술 마스터리 (Sword Mastery)

필수:
- Stardew Valley 1.6.x
- SMAPI 4.3.0 이상

선택:
- Generic Mod Config Menu (GMCM)
  없어도 모드는 작동하지만 게임 안에서 키/HUD 위치 설정이 편해집니다.

설치 - Vortex:
1. Nexus Mods에서 Mod Manager Download를 선택합니다.
2. Vortex에서 Stardew Valley 프로필에 설치/활성화합니다.
3. SMAPI로 게임을 실행합니다.

설치 - 수동:
압축 안의 SwordMastery 폴더를 그대로 Stardew Valley/Mods 폴더에 넣습니다.

정상 구조:
Stardew Valley/
└─ Mods/
   └─ SwordMastery/
      ├─ SwordMastery.dll
      ├─ manifest.json
      ├─ assets/
      └─ i18n/

주의:
- config.json은 첫 실행 후 자동 생성됩니다.
- Android 지원은 별도 테스트가 끝나기 전까지 실험적 지원으로 취급합니다.
