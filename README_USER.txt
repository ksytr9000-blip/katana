Sword Mastery
=============

Requirements:
- SMAPI 4.3.0 or later
- Generic Mod Config Menu is optional

Installation:
1. Extract the SwordMastery folder into Stardew Valley/Mods.
2. Launch the game through SMAPI.

Languages:
- English (default)
- Korean

English is the default language. Korean can be selected from Generic Mod Config Menu.

Default keys:
K   Open Sword Mastery menu
F6  Swordsman's Step
F7  Slash
F8  Calico Style Swordsmanship
F9  Selected active Secret Art
F10 Selected active Ultimate
