SwordMastery PATCH 23 - 검술의 극 특수 몬스터 처치 확장
===========================================================

PATCH 22까지 모두 포함하는 누적형 패치입니다.
현재 저장소에는 PATCH 23만 덮어쓰면 됩니다.

검술의 극 특수 처치 대상:
- 미라 (Mummy)
- 갑충 (Armored Bug)
- 바위게 (Rock Crab 계열)

처리 방식:
- 검술의 극의 확정 치명타는 그대로 유지
- 특수 몬스터가 범위 안에 있으면
  vanilla bomb-type 99,999 마무리 판정을 최대 3회 적용
- 미라 부활, 갑충 무기 면역, 바위게 껍질/방어 상태를 우회
- 기존 사망/드랍 처리는 가능한 한 게임의 damageMonster 로직을 그대로 사용
- 돌/광석 등 LOS 장애물 뒤에서도 검술의 극 판정 유지

업로드:
압축 해제 후 저장소 루트에 그대로 덮어쓰기.
