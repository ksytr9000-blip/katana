이번 수정:

[1] 툴팁

- 설명은 tinyFont
- "기초검술 A/B/C", "오의 A/B/C" 같은 분류문구 제거
- 현재 투자 / 상태도 tinyFont로 축소

[2] 기초검술 데미지 하향
- 전체 고정 피해량을 크게 낮춤
- 초반 몬스터가 한 번에 죽어서 다단히트가 안 보이는 문제 완화

[3] 다단히트
- 검사의 발걸음 3단계: 4회 타격을 8틱 간격으로 분리
- 칼리코류: 3/4/6회 타격을 8틱 간격으로 분리
- 검술의 정점: 3/6/10회 타격을 6틱 간격으로 분리

[4] 오의 구현
A 일섬
- 오의 키로 발동
- 전방 장거리 대쉬 + 경로 강타
- 단계가 오를수록 경로 폭 증가

B 검기
- 패시브
- 기본 검 공격(MouseLeft/C/ControllerX)에 자동 검기 발사
- 1단계: 작은 검기, 1회 명중 후 소멸
- 2단계: 사거리/폭 증가, 2회 관통
- 3단계: 맵 단위 장거리, 대형 검기, 사실상 다수 관통
- 거리/관통 횟수에 따라 피해 감소

C 검술의 정점
- 오의 키로 발동
- 전방위 3/6/10회 다단 타격
- 단계가 오를수록 범위 증가

[5] 극의 구현
A 검술의 극
- 패시브
- 주변 적을 약 0.75초마다 자동 참격
- 단계별 범위/피해 증가
- 다른 행동 중에도 업데이트됨

B 보법의 극
- 극의 키로 발동
- 쿨다운 없음
- 단계별 이동거리/경로 피해 증가

[기본키]
F6 = 검사의 발걸음
F7 = 참격
F8 = 칼리코류 검술
F9 = 오의
