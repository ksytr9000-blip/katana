SwordMastery PATCH 16 - EFFECT / AOE REWORK
==============================================

PATCH 15까지의 모든 내용을 포함하는 누적형 패치입니다.
현재 저장소에는 PATCH 16만 덮어쓰면 됩니다.

[기초검술 C]
- 전방의 한 고정점을 모든 연속 참격이 관통하도록 변경
- 원을 도는 듯한 빈 중심 이펙트 제거
- 타격마다 다른 각도의 직선 참격이 같은 지점을 반복해서 벰
- 타격 간격: 5틱 -> 9틱으로 증가

[오의 C - 검술의 정점]
- 캐릭터 중심을 모든 참격이 관통
- 기초검술 C보다 훨씬 크고 굵은 대형 검격
- 한 타격마다 여러 개의 교차 참격 발생
- 일부 타격은 거대한 X형 마무리 참격 추가
- 이펙트 크기 확대
- 타격 간격: 4틱 -> 8틱으로 증가

[일섬]
- 초승달/Arc 이펙트 완전 제거
- 시작점 -> 종료점의 직선 빔 이펙트만 표시
- 이펙트 폭 = 실제 공격 판정 폭과 동일
  * 1단계: 1칸
  * 2단계: 5칸
  * 3단계: 10칸
- 99,999 확정 치명타 및 crit 효과음 유지

[돌/광석 뒤 범위 공격]
- 몬스터의 ignoreDamageLOS를 타격 순간만 임시 활성화
- 바위 / 광석 / 고체 오브젝트 뒤의 몬스터도 범위 안이면 공격 가능
- 적용:
  * 기초검술 B 근접 범위기
  * 기초검술 C
  * 검술의 정점
  * 검술의 극
  * 일섬
  * 관통형 검기
- 일반 사망/드랍/킬 처리 로직은 vanilla damageMonster를 그대로 사용

업로드:
압축 해제 후 저장소 루트에 그대로 덮어쓰기.
