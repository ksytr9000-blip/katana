SwordMastery PATCH 29 - NEXUS / I18N RELEASE PREP
===================================================

This is cumulative from PATCH 28.

New:
- English is now the default in-game language.
- Korean is automatically selected when Stardew Valley is set to Korean.
- Added i18n/default.json and i18n/ko.json.
- Localized skill names/descriptions, HUD, GMCM, quests, custom items, combat messages, and reward messages.
- manifest.json now uses the English public name "Sword Mastery".
- Added UpdateKeys: Nexus:53641.
- Added Nexus English/Korean description drafts.
- Added Nexus upload checklist.
- Existing GitHub Actions Nexus/Vortex packaging remains enabled.

Language selection:
The mod follows the Stardew Valley game language automatically through SMAPI.
There is no separate mod-language toggle.
